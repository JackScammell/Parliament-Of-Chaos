# Changelog

Display the Parliament of Chaos changelog — version history, new features, breaking changes, and bug fixes across all releases.

## Process

1. Read `CHANGELOG.md` from the plugin root
2. Display the full contents

## Output

The full CHANGELOG.md content, showing all releases in reverse chronological order with:
- Version number and release date
- Added features and new commands
- Changed behaviour
- Fixed bugs
- Breaking changes (if any)
